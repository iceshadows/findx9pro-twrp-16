# 01 平台与机型调研

## 机型

| 项 | 值 | 来源 |
|---|---|---|
| 入网型号 | **PLG110** | OPPO 官网 Find X9 Pro 参数页 |
| 对应零售机 | OPPO Find X9 Pro | 同上 |
| 发布 | 2025-10-16 | 百度百科 |
| SoC | 天玑 9500 / **MediaTek MT6993** | 官方参数 + 平台代号推导 |
| 系统 | Android 16 / ColorOS 16 | 出厂版本 |

> 别的后缀需要单独确认分区表。

## 平台特性（决定移植方案）

1. **GKI 内核**。Android 16 对应 GKI 6.12，内核在 `boot.img` 里，厂商定制放在 vendor 模块。
   → TWRP 不需要自己编内核，用 prebuilt 思路：保留官方 boot.img，只换 vendor_boot 的 ramdisk。
2. **A/B + 虚拟 A/B**。所有可刷分区带 `_a`/`_b` 后缀，`slotselect`。
3. **动态分区**。`system`/`vendor`/`product`/`system_ext`/`odm`/`*_dlkm` 都在 `super` 里，
   再加 ColorOS 的 `my_*` 系列逻辑分区。
   → recovery.fstab 里这些要走 `logical`，不能写设备路径。
4. **没有 recovery 分区**。Android 13 起 recovery ramdisk 归入 `vendor_boot`，
   vendor_boot header v4 用 **vendor ramdisk table** 描述多个 ramdisk 片段：
   ```
   type 1 = platform (MTK 的 kernel modules + init 脚本)
   type 2 = recovery (TWRP 就装在这里)
   type 3 = dlkm
   每个片段按 page(4096) 对齐拼接成 vendor_ramdisk blob，table 记录 offset/size。
   ```
   TWRP 的 `BOARD_MOVE_RECOVERY_RESOURCES_TO_VENDOR_BOOT` 正是产出 type=2 片段。
5. **AVB**。`vbmeta` / `vbmeta_system` / `vbmeta_vendor` 三个校验分区。
   修改后的 vendor_boot 哈希必然不匹配，需 `fastboot --disable-verification flash vbmeta`。

## 官方开源资源

OPPO 在 GitHub 上按平台公开内核源码，MT6993 相关仓库（分支名形如
`oppo/mt6993_b_16.0.0_find_x9`）：

- `oppo-source/android_kernel_oppo_mt6993` — 内核源码
- `oppo-source/android_kernel_modules_and_devicetree_oppo_mt6993` — 模块与设备树

用途：
- 交叉核对 vendor_boot 里 DTB 对应的硬件树（触摸 IC、背光、存储控制器）。
- 编译 recovery 需要的 vendor 模块（触摸驱动等）。
- **注意**：官方源码是 GPL 合规发布，不能替代固件；TWRP 首版仍以固件里的 prebuilt 二进制为准。

## 参考实现

同为 MTK + Android 16 的公开移植可直接对照：

- `YorokobiMaster/device_xiaomi_dash_twrp`（分支 `twrp-16.0`，Dimensity 9400/MT6991）
  —— 本工程的设备树结构、`BOARD_MOVE_RECOVERY_RESOURCES_TO_VENDOR_BOOT` 用法、
  repack 思路均参照它。它的 README 明确记录了几个真实坑：
  - recovery 必须是独立的 `type=2 name=recovery` 片段；
  - 不能整体替换官方 vendor_boot（会丢模块与 DTB）；
  - 官方 ramdisk 的格式必须保留，否则第二个槽无法启动。

## 与旧机型移植的差异（避免踩坑）

| 旧做法 | PLG110 上为什么不行 |
|---|---|
| 刷 `recovery.img` 到 recovery 分区 | 没有该分区 |
| 把 boot.img 换成 TWRP 的 | GKI + AVB，且会丢掉官方第一阶段 init |
| fstab 里写 `/dev/block/.../by-name/system` | 动态分区必须写分区名 + `logical` |
| 用 `mkbootimg` 直接打包 vendor_boot | 会丢掉 MTK 的 kernel module 片段 |
